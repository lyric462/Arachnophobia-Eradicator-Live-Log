# Arachnophobia Eradicator – Live Log

Source code and documentation for the optional Live Log and debugging tool of the **Arachnophobia Eradicator – Insectoid Protection** mod for **The Witcher 3: Wild Hunt**.

The Live Log is an optional debugging tool. It is **not required** for the main Arachnophobia Eradicator mod to function.

## Purpose

The Live Log was created to make testing and debugging the Arachnophobia Eradicator mod easier.

It monitors the local Witcher 3 script log and displays log entries generated by the mod in real time.

This can be used to verify that the mod is detecting and removing insectoid enemies correctly.

The viewer can display information such as:

- kill events
- detection information
- summary information
- status and heartbeat messages
- mod startup messages
- other log entries generated through the `Arachnophobia` log channel

---

## Included Files

This repository contains the complete source code of the Live Log package.

### `Arachnophobia_LogViewer.ps1`

This is the main PowerShell log viewer.

The script:

1. Searches for the Witcher 3 script log.
2. Supports both `scriptslog.txt` and `scriptlog.txt`.
3. Checks the standard Documents location and the OneDrive Documents location.
4. Waits for the log file if it is not currently available.
5. Monitors the log while the game is running.
6. Filters for entries containing `Arachnophobia`.
7. Displays matching entries in real time.
8. Writes matching Arachnophobia entries to a local `Arachnophobia_Kills.log` file.
9. Detects when the log is recreated or truncated and adjusts its reading position accordingly.

If a second monitor is available, the script also attempts to move and resize its console window on the additional display.

The viewer performs local log monitoring and does not require a separate compiled application.

---

### `Start_Witcher3_Arachnophobia.cmd`

This is a Windows batch launcher.

It starts:

`Start_Witcher3_Arachnophobia.ps1`

using Windows PowerShell.

It is provided as a convenient way to start the Live Log setup without manually opening PowerShell.

---

### `Start_Witcher3_Arachnophobia.ps1`

This is the main launcher and logging setup script.

It:

1. Determines the Witcher 3 installation directory based on the location of the script.
2. Checks for the compiled Witcher 3 script cache:
   `content\content0\x64.final.redscripts`
3. Creates the following backup directory when required:
   `ArachnophobiaLogViewer\ScriptCacheBackup`
4. Moves the existing compiled script cache into a timestamped backup file instead of permanently deleting it.
5. Uses a local marker file to keep track of the logging setup state.
6. Starts the `Arachnophobia_LogViewer.ps1` log viewer.
7. Searches for the local Steam installation.
8. Starts The Witcher 3 through Steam using AppID `292030`.
9. Launches the game with the `-debugscripts` argument.

The cache handling allows the game to regenerate the compiled script cache when the logging setup requires it.

The original compiled cache is moved to a backup location rather than permanently deleted.

---

### `Reset_Arachnophobia_Logging.cmd`

This is a Windows batch wrapper for the logging reset script.

It starts:

`Reset_Arachnophobia_Logging.ps1`

using Windows PowerShell.

---

### `Reset_Arachnophobia_Logging.ps1`

This script resets the local Witcher 3 script-cache setup used by the Live Log.

It:

1. Determines the Witcher 3 installation directory.
2. Checks for:
   `content\content0\x64.final.redscripts`
3. Creates:
   `ArachnophobiaLogViewer\ScriptCacheBackup`
4. Moves the existing compiled script cache into a timestamped backup file.
5. Removes the `logging_ready.flag` marker when present.
6. Informs the user that the next launch through the Start script will rebuild the cache with `-debugscripts`.

The existing compiled cache is moved to a backup location instead of being permanently deleted.

# How the Live Log Works

The general workflow is:

1. The user starts `Start_Witcher3_Arachnophobia.cmd`.
2. The launcher performs the required logging/cache setup.
3. The PowerShell log viewer is started.
4. Steam launches The Witcher 3 with the `-debugscripts` argument.
5. The Witcher 3 writes script information to its local script log.
6. The Arachnophobia Eradicator mod writes its own messages using the `Arachnophobia` log channel.
7. The PowerShell viewer monitors the log file.
8. Matching entries are displayed in real time.
9. Matching entries are also written to `Arachnophobia_Kills.log`.

Example log event types include:

```text
[KILL]
[SUMMARY]
[STATUS]
[START]
[LOG]
```

The Live Log is intended for debugging and verification. It is not required for normal gameplay.

# Installation and Usage

The Live Log is an optional component.

The main Arachnophobia Eradicator mod should be installed separately according to its Nexus Mods installation instructions.

To use the Live Log:

1. Place the `ArachnophobiaLogViewer` folder in the Witcher 3 installation directory.
2. Make sure the five included scripts are inside the folder.
3. Run:

   `Start_Witcher3_Arachnophobia.cmd`

4. The launcher starts the log viewer and launches The Witcher 3 through Steam.
5. The log viewer can then be used to monitor Arachnophobia-related script events while playing.

The expected folder structure is:

```text
The Witcher 3 installation folder
│
└── ArachnophobiaLogViewer
    ├── Arachnophobia_LogViewer.ps1
    ├── Reset_Arachnophobia_Logging.cmd
    ├── Reset_Arachnophobia_Logging.ps1
    ├── Start_Witcher3_Arachnophobia.cmd
    └── Start_Witcher3_Arachnophobia.ps1
```

# Resetting the Logging Setup

If the logging setup needs to be reset:

1. Close The Witcher 3.
2. Run:

   `Reset_Arachnophobia_Logging.cmd`

3. The existing compiled script cache is moved to:

   `ArachnophobiaLogViewer\ScriptCacheBackup`

4. The logging marker is removed when present.
5. Start the game again using:

   `Start_Witcher3_Arachnophobia.cmd`

The game can then regenerate the required compiled script cache.

# Source Code and Build Information

This project does **not** require compilation.

The Live Log consists of plain-text Windows PowerShell (`.ps1`) and batch (`.cmd`) scripts.

There is no compiled executable or binary included in this project.

The source code is provided directly in this repository.

To reproduce the Live Log setup from the source:

1. Download or clone this repository.
2. Create an `ArachnophobiaLogViewer` folder inside the Witcher 3 installation directory.
3. Place all five source files into that folder.
4. Run:

   `Start_Witcher3_Arachnophobia.cmd`

The `.cmd` files are launcher wrappers for the corresponding PowerShell scripts.

No additional compilation step is required.
